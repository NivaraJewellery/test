# V30F — Bangle size in order views and emails

- Order confirmation modal now shows Size + UOM for bangle items only.
- Customer order detail/PDF also show bangle size.
- Admin Orders page shows Size + UOM for bangle items only.
- Order notification and customer confirmation emails include an explicit Size label for bangle items.
- Newly created order records now retain product type/category so future display logic can distinguish bangles cleanly.
- Non-bangle items do not display a size line.
