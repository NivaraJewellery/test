# Shop by Category – Launch Update

The homepage category section now uses the approved rectangular image-card layout:

- Centered **SHOP BY CATEGORY** heading.
- Large category image with category name below it.
- **Explore Now →** call to action on every category card.
- Five cards visible on wide desktop layouts.
- Horizontal scrolling with left/right controls when additional categories are available.
- Responsive 3-card tablet and 2-card mobile layouts with touch scrolling.
- Category images continue to use the image configured from Admin, with the existing product-image fallback when no dedicated category image has been assigned.
