# Nivara Jewellery Search + Filter Build 2

Built on top of the fixed Mobile Filter Build 1.

New feature:
- General product search above the catalogue
- Works on desktop and mobile
- Searches product name, type/category, collection name/slug, product code and description
- Case-insensitive
- Handles simple singular/plural searches (example: Bangle / Bangles)
- Search works together with Category, Price, Availability and Sort filters
- Live results with a short debounce
- Clear-search button
- Result count text
- Search-aware "No products found" message

Example:
Typing "Bangles" lists matching bangle products.
